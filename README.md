# 팀 비밀 금고

API 키, 비밀번호, 토큰 같은 민감한 정보를 팀원과 안전하게 보관하고 공유하는 웹 서비스입니다.

내용은 브라우저에서 암호화된 뒤 서버로 전송되며, 서버에는 암호문만 저장됩니다. 마스터 비밀번호도 서버로 보내지 않습니다.

아이펠 학습 실습으로 만들었습니다. (백엔드/프론트엔드 분리, 해시/솔트, 공개키, 대칭키를 실제로 사용)

## 주요 기능

- **회원가입 / 로그인** — 사용자명과 마스터 비밀번호로 가입하면 개인 키가 자동으로 만들어집니다.
- **비밀 저장** — 제목과 내용을 입력하면 내용이 암호화되어 저장됩니다.
- **비밀 보기 / 복사** — 목록에서 [보기]를 누르면 복호화되어 값이 표시되고, 클립보드로 복사할 수 있습니다.
- **팀원 공유** — 사용자명을 입력해 특정 팀원에게만 공유할 수 있습니다. 공유받은 사람만 자기 계정으로 열 수 있습니다.
- **삭제** — 소유자가 삭제하면 공유받은 사람의 접근도 함께 사라집니다.
- **복구 키** — 가입 시 복구 키가 한 번 발급됩니다. 마스터 비밀번호를 잊었을 때 이 키로 새 비밀번호를 설정할 수 있습니다. 로그인 상태에서 재발급도 가능합니다.

## 실행 방법 (Windows / git-bash)

```bash
# 1) 가상환경 생성·활성화
python -m venv .venv
source .venv/Scripts/activate

# 2) 설치
pip install -r backend/requirements.txt

# 3) 세션키 설정 (선택 — 안 하면 서버 재시작 때 로그인이 풀립니다)
python -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(32))" > .env

# 4) 실행 (개발용)
cd backend && python app.py
#   → 브라우저에서 http://127.0.0.1:5000
```

인터넷에 공개하려면(다른 사람도 접속) → `📘배포_안내서.md` 참고. 내 PC + Cloudflare Tunnel로 도메인·포트개방 없이 무료로 공개할 수 있습니다.

## 폴더 구조

```
팀비밀금고/
├─ backend/                  # Flask 서버 (API + 화면 서빙)
│  ├─ app.py                 # 개발용 진입점
│  ├─ 서버실행.py             # 배포용 진입점(waitress)
│  ├─ config.py  db.py  schema.sql
│  └─ routes/ 인증.py  시크릿.py  공유.py
├─ frontend/                 # 화면과 암호화 로직
│  ├─ index.html
│  ├─ css/스타일.css
│  └─ js/ 암호.js  api.js  앱.js
├─ 공유암호화_증거테스트.mjs   # 동작 확인용 스크립트
├─ 복구키_증거테스트.mjs
├─ 📘배포_안내서.md
└─ README.md
```

## 기술 스택

- **백엔드**: Python + Flask, SQLite
- **프론트엔드**: HTML / CSS / JavaScript (브라우저 내장 WebCrypto로 암호화)
- **암호화**: 비밀번호 해시(bcrypt), 키 유도(PBKDF2), 대칭 암호(AES-GCM), 공개키 암호(RSA-OAEP)

## 참고

- 로컬(`127.0.0.1`)에서 바로 실행할 수 있고, 인터넷 공개도 가능합니다(`📘배포_안내서.md`). 암호화 특성상 접속은 HTTPS 또는 localhost에서만 정상 동작합니다.
- 제목은 암호화하지 않고 그대로 저장되므로 제목에 민감한 정보를 넣지 마세요.
- 마스터 비밀번호와 복구 키를 모두 잃으면 저장한 내용을 되살릴 수 없습니다.
